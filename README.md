# Fulfil Migration Auditor

A structured ERP data migration auditing framework designed to validate, reconcile, and report discrepancies during system migrations.

## Features
- Schema validation
- Reconciliation engine
- Rule-based validation
- Exception reporting
- Modular architecture

## Tech Stack
Python, SQL, ETL, ERP Data Modeling

## Use Case
Built to support ERP implementations and data migration validation for operations-driven systems.
